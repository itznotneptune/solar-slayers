# Solar Slayers

Client-side Fabric mod with quality-of-life features for slayers on SolarSkies. Unofficial. By ItzNotNeptune.
It only reads what the server already shows; it sends nothing on its own.

## Minecraft versions
Each supported Minecraft version has its own branch:

| Branch | Minecraft | Fabric API |
|---|---|---|
| `1.21.11` (default) | 1.21.11 | 0.141.6+1.21.11 |
| `1.21.9` | 1.21.9 – 1.21.10 | 0.134.1+1.21.9 |
| `26.3` | 26.3 | 0.166.2+26.3 |

The jar name includes the Minecraft version, e.g. `solarslayers-0.1.0+1.21.11.jar`. Fixes are made on `1.21.11` and
merged into the other branches. On `1.21.9` only `compat/Compat.java` differs. `26.3` is an unobfuscated version with
many renamed Minecraft APIs, so its branch carries its own port of the code and needs Java 25 to play.

## Features
- **Boss highlight**: your slayer boss is drawn full-bright with a layer of the colour you pick over it, so the colour
  stays true on any texture (opacity adjustable). "Only my boss" uses the `Spawned by: <you>` label above it.
- **Miniboss highlight**: same, for minibosses such as the Moonlit Hunter. New minibosses are learned from the
  `MINIBOSS! A <name> spawned` chat line.
- **Minion highlight**: the minions a boss calls (the Moonfang Alpha's pups at T3) in their own colour. With
  "Only my boss" on, only minions within 24 blocks of your boss.
- **Blaze minion highlight**: the Solar Flare's minions (`Solar Flare Minion`) in their own colour, under
  Blaze Slayer in the menu. Follows "Only my boss" the same way.
- **Prismarine Shade**: darkens placed prismarine, prismarine bricks and dark prismarine (and their stairs, slabs
  and wall) from 0% (unchanged) to 100% (black), under World. The model overrides are generated by
  `tools/gen_prismarine.py`.
- **No quest warning**: red title, white subtitle and a ding when you hit slayer mobs without an active quest.
- **Slayer progress HUD**: boss HP, time left and ward state while the boss is alive; otherwise XP until the boss and
  kills left (XP per kill is configurable, default 5).
- **Pity meter HUD**: selected pity item and meter progress; with none set, the XP saved (from the kill summary).
- **Slayer timer HUD**: time to spawn and to kill the boss (from the `SLAYER QUEST STARTED!`, `SLAYER BOSS SPAWNED!`
  and `SLAYER BOSS SLAIN!` chat lines), last run, bosses this session, bosses per hour, average and best. Gaps over
  10 minutes between slayer messages don't count against the hourly rate.
- **Upgrade tracker**: right-click an item in the Upgrade Shop to track it (the click is not sent to the server, so it
  never crafts). Shows level, Essence and materials against what the item needs.
- **Slayer menu link**: a clickable chat line after each boss kill that runs `/slayer`.

Open the settings with `/slayer+`, `/slayerplus`, or a key set in Options → Controls → Key Binds → Solar Slayers →
Open Mod GUI (unbound by default). HUD panels are moved in General → Edit HUD.

## Install
Put the jar for your Minecraft version and [Fabric API](https://modrinth.com/mod/fabric-api) in your Fabric mods folder.

## Build
Gradle must run on **Java 25** (Loom needs it); the 1.21.x branches target Java 21, the 26.3 branch Java 25. Set `JAVA_HOME` to a JDK 25, or set
`org.gradle.java.home` in `gradle.properties`, then run `./gradlew build`. The jar is written to `build/libs/`.
